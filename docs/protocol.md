# 云台私有协议指令帧解析

本文档描述控制中间件实际使用的指令帧格式，依据云台厂商《云台私有协议 V1.0.2》与源码实现整理。厂商原始文档版权归其所有，未随本仓库分发；本文内容为便于阅读源码而整理的技术说明。

## 1. 帧总览

控制指令帧为**定长 40 字节**。结构体原型为 `Gcu2GbcPkt_t`。

| 偏移 | 字段 | 长度 | 说明 |
|------|------|------|------|
| 0–1 | `sync[2]` | 2 | 同步头，固定 `0xA9 0x5B` |
| 2 | `cmd` | 1 | 命令字节：`trig[3 位] + valu[5 位]` |
| 3 | `aux` | 1 | 辅助字节：`reserved[3 位] + fl_sens[5 位]` |
| 4–12 | `gbc[3]` | 9 | 三轴控制数据，每轴 3 字节 |
| 13–25 | `uav` | 13 | 载机数据（本项目填 0，`valid=0` 表示无效） |
| 26–37 | `cam` | 12 | 相机数据（本项目填 0） |
| 38–39 | `crc` | 2 | CRC-16 校验，**大端序** |

### 1.1 `gbc[3]` 三轴控制段布局

三轴顺序固定为 **Roll → Pitch → Yaw**，每轴占 3 字节：

| 相对偏移 | 字段 | 长度 | 说明 |
|----------|------|------|------|
| +0 | `control_byte` | 1 | `reserved[3] + go_zero[1] + wk_mode[2] + op_type[2]` |
| +1..+2 | `op_valu` | 2 | `int16` 有符号角度值，**小端序** |

由此得到各轴绝对偏移：

| 轴 | `control_byte` 偏移 | `op_valu` 偏移 |
|----|---------------------|----------------|
| Roll | 4 | 5–6 |
| Pitch | 7 | 8–9 |
| Yaw | 10 | 11–12 |

## 2. 命令字节 `cmd`

`cmd = (trig << 5) | valu`，本项目 `trig` 恒为 `000`。

| `valu` | 含义 |
|--------|------|
| 1 | 陀螺仪校准 |
| 2 | **启动云台** |
| 3 | 停止云台 |
| 4 | **手动控制**（角度控制） |

程序运行流程：启动时先发送一帧 `cmd=2` 启动命令，随后持续发送 `cmd=4` 控制帧。

## 3. 控制字节 `control_byte`

```
 7  6  5 | 4 | 3  2 | 1  0
 reserved|go_zero|wk_mode|op_type
```

| 字段 | 位宽 | 取值 |
|------|------|------|
| `reserved` | 3 | `000` |
| `go_zero` | 1 | `0`=正常，`1`=归零 |
| `wk_mode` | 2 | `0`=Follow，`1`=Lock，`2`=FPV |
| `op_type` | 2 | `0`=角度控制，`1`=比例角速度，`2`=真实角速度 |

本项目采用 **角度控制**（`op_type=0`），因此控制字节由工作模式唯一确定：

- Follow：`0x00`
- Lock：`0x04`
- FPV：`0x08`

## 4. 角度量化与坐标系

- 浮点角度按 **×100** 转为 `int16`，即协议最小分辨率 `0.01°`。
- 取值范围需钳制在 `[-32768, 32767]`，对应 `[-327.68°, 327.67°]`。
- **Pitch 取反**：受云台安装姿态影响，Pitch 轴输入需反向修正，实现为 `int16_t(-pitch * 100)`。Roll / Yaw 方向系数分别为 `1 / 1`（见 `Config.ROLL_INVERT`、`Config.YAW_INVERT`）。

## 5. CRC-16 计算

采用与厂商 C 代码一致的实现（CRC-16/X-25 风格的高半字节查表法），校验范围为**前 38 字节**：

```python
CRC_TABLE = [
    0x0000, 0x1021, 0x2042, 0x3063, 0x4084, 0x50a5, 0x60c6, 0x70e7,
    0x8108, 0x9129, 0xa14a, 0xb16b, 0xc18c, 0xd1ad, 0xe1ce, 0xf1ef
]

def calculate_crc16(data: bytes) -> int:
    crc = 0
    for byte in data:
        da = (crc >> 12) & 0x0F
        crc = ((crc << 4) & 0xFFFF) ^ CRC_TABLE[da ^ (byte >> 4)]
        da = (crc >> 12) & 0x0F
        crc = ((crc << 4) & 0xFFFF) ^ CRC_TABLE[da ^ (byte & 0x0F)]
    return crc
```

**字节序陷阱**：协议主体全部为小端序，唯独 CRC 字段为大端序，写入时必须使用 `struct.pack('>H', crc)` 或等价的 `packet[38] = crc >> 8; packet[39] = crc & 0xFF`。

## 6. 完整构帧示例

以 Follow 模式、Pitch=+10°、Yaw=+10°、Roll=0 为例：

```
偏移 0-1 : A9 5B                    # sync
偏移 2   : 04                       # cmd=4 手动控制
偏移 3   : 00                       # aux
偏移 4-6 : 00 00 00                 # Roll: control_byte=0x00, op_valu=0
偏移 7-9 : 00 18 FC                 # Pitch: control_byte=0x00, op_valu=-1000 (0xFC18 小端)
偏移 10-12: 00 E8 03                # Yaw: control_byte=0x00, op_valu=1000 (0x03E8 小端)
偏移 13-25: 00 ×13                  # uav
偏移 26-37: 00 ×12                  # cam
偏移 38-39: CRC-16 (大端)
```

## 7. 接收方向

云台返回数据包长度为 **26 字节**。基础版 Python 实现（`gimbal_controller.py`）在串口模式下会读取该响应包并打印其十六进制内容，用于链路自检。
